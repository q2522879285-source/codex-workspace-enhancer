# Codex Workspace Enhancer v3.0.3 更新说明

本次是 v3.0.2 的启动与侧栏适配修复版。工作地图、浏览器、资料库、主题、会话整理与 Tibo 活动概率规则保持现有功能，沿用原介绍图。

## 更新内容

- **Node 环境**：优先使用安装记录中的有效 Node 路径，失效后再从 PATH 查找，减少不同机器环境造成的启动失败。
- **调试端口**：快捷方式不再固化端口；默认采用安装记录，仅复用确认属于 Codex 的活动端口；显式参数优先。
- **竞争启动**：launcher 与 injector-start 使用独占文件锁，重复启动不破坏已有 PID、日志与就绪标记。
- **错误可见性**：watch 输出具体错误、端口与重试提示；连续同错只记录一次，成功恢复后再次出错会重新记录。
- **原生侧栏适配**：控件和卡片统一绑定当前可见宿主，处理隐藏旧宿主、宿主替换及 hidden/style/class 可见性变化。
- **减少无效刷新**：移除鼠标移入触发的全量同步，过滤插件自身写入与正文 childList 更新，只在时间文字变化时写入。
- **MOKE 资料库**：隐藏、折叠或切走时释放卡片 DOM，后台同步保留；打开先显示 50 条，每次“显示更多”增加 50 条；未变内容不重建，切换资料来源或状态后正确恢复列表。
- **窄右栏交互**：复用现有间距变量并允许标签横向滚动，保留原布局、字体与状态展示。

## 回归与压力测试

新增 18 项回归测试；全量 `npm test -- --test-concurrency=1` 共 245 项，**241 通过、0 失败、4 项 macOS 平台测试跳过**。

| 检查 | 结果 |
| --- | --- |
| 12 个竞争启动进程 | 已有 flags、日志、PID 保持；锁释放后可重新获得 |
| 空闲 1.2 秒、2000 次 pointerover、20 次正文更新 | 三类场景全量侧栏扫描均为 0 |
| 3500 条资料、70 页同步 | 隐藏卡片 0；打开 50 条，显示更多后 100 条；关闭后迟到响应不建卡 |
| 两次 MOKE→其他资料来源→MOKE | 恢复 50 条卡片；未变内容不重建，不重新请求资料 |
| 原生 A→B 切换，不手动 refresh | 活动任务、B 摘要与 Token 回读正确，隐藏资料库卡片仍为 0 |
| 1440 / 1200 / 1120 视口，300 / 264 / 248px 右栏 | 空闲和运行中共六组，真实鼠标点击与 Tab→Enter 均可进入资料库 |
| 30 次资料库任务切换、30 次重注入 | 三批销毁后 documents=1、nodes=739、listeners=92，计数一致 |
| 通用渲染器 100 轮同步、1000 次刷新、30 次重注入 | 页面异常与未处理 rejection 均为 0；40 次原生刷新调用合并为 2 次 refetch |
| 60 次重注入后的 GC 抽样 | 第 20→60 次 heap 增长 1708 bytes；DOM=764、listeners=78，不增长 |
| 并发任务读取、乱序回包与本地 HTTP 故障 | 缓存上限 64，最终 pending=0，HTTP 压力结束后 retained sockets=0 |

测试可从源码运行。renderer 测试需要已有 Playwright 与 Chromium，可通过 `RENDERER_PLAYWRIGHT` 和 `RENDERER_BROWSER` 指定本地路径。纯 DOM fixture 使用固定 origin 与路由响应，不再依赖随机 HTTP 端口。

## 验证范围

启动测试使用真实 PowerShell、Node 和文件锁，进程激活及 CDP 目标使用隔离 fixture；渲染器使用隔离 Chromium 与合成原生 DOM。真实桌面完整冷启动、朋友机器现场、真实 MOKE 授权及 live UI 尚未验收。内存抽样不是完整的零泄漏证明。

资料库采用分批显示，不是完整虚拟列表；连续点击“显示更多”仍会增加 DOM。隐藏资料库不暂停后台摘要、任务或资料同步。Tibo 公共源仍按需启用，与当前账号真实额度分开。

发布附件包含 Windows ZIP、完整 Skill ZIP、两个 SHA-256 校验文件和本更新说明。升级方法与配置边界不变。
