# Codex Workspace Enhancer v3.0.0 更新说明

v3.0.0 相对正式发布的 v2.0.0，新增两张工作地图、内嵌浏览器、MOKE 资料库、原生账号与额度管理，并更新启动体验、主题和任务接续。原生对话与项目结构继续保留，各项外部服务和自动整理规则按需启用。

## 两张工作地图

**全局工作地图**把方向、事项和关联会话放在一起。可以在地图、列表和关系视图之间切换，自由拖动与缩放，记录状态、重点、下一步和备注，撤销修改并导出 JSON。事项与原生会话分别管理，一件事可以关联多个会话。

**每任务 Task Map**用于单个任务的核心计划。手动计划优先保留，状态同步带来源与时间；支持节点编辑、自建、删除、键盘移动与导出。展开后使用更宽的画布，收起后恢复对话布局。两张地图分开存储。

地图搜索覆盖地图字段和已关联会话标题；关联选择器支持按会话标题和工作目录分页查找。可选 CortexDB 为地图字段及关联会话标题/ID 建立单向词法索引，需要用户另行配置兼容程序。普通地图编辑无需 CortexDB，索引也不替代地图状态或搜索全部聊天正文。

## 内嵌浏览器与 MOKE 资料库

工作台新增多页签浏览器，支持地址输入、搜索、前后导航、刷新和重开页签，保存页签元数据与导航历史。可快速打开原生会话，在明确提交后向选定会话发送消息；切页签、打开会话和选择附件都不会自动发送。

MOKE 资料库提供分类检索、分页、详情正文、Skill 文件预览、复制及引用到当前输入。云资料与本地项目资产分开管理。用户需自行配置原生 MCP server `moke` 并完成授权；打开授权页只代表进入登录流程。预览或引用 Skill 文件不会自动安装 Skill。

## 会话自动命名与归组

新增可选会话整理规则。用户采用模板后，主助手在当前任务首次产生实质结果时执行一次，按 `模块名｜持续目标` 命名，并放入对应模块分区。

整理通过原生会话工具完成，写入后重新读取确认；摘要记录整理结果，避免重复执行。已有手动标题、置顶、自定义分类和项目容器保留，不批量整理旧会话，不改变侧栏布局或排序设置。安装本身不会开启后台改名，也不会修改全局规则、hooks 或信任状态。

[会话整理规则模板](https://github.com/q2522879285-source/codex-workspace-enhancer/blob/main/templates/task-organization-rules.md)

## 主题、任务 Token 与切换体验

新增多主题、自定义配色、明暗设置，以及卡片底色和分隔线调整；任务右栏、地图、浏览器与资料库使用统一样式。

当前任务可显示原生 rollout 记录中的最近用量、累计 Token 和上下文窗口。异步回包限定当前活动会话，忽略旧任务结果，同时改进导航标签的持久化和任务切换状态。任务 Token 来自原生事件，与账号剩余额度分开展示。

## 原生额度、重置卡与本机账号

额度展示新增原生 `account/rateLimits/read` 来源，显示实际额度窗口、正常重置时间和接口提供的可用重置卡。接口不可用时保留回退或不可用状态，重置卡是否存在取决于当前版本和账号。

本机账号管理支持列表、同步当前账号、添加账号与明确选择切换。切换通过原生登录调用，并回读账号状态确认结果。账号 profiles 保存在用户本机，包含认证信息，不进入发布包。

新增原生更新快捷入口，确认后调用 Codex 自身的检查或更新界面，沿用官方更新流程。

## Tibo 公共动态与概率参考

可选 Tibo 公共动态展示事件摘要、来源、预期时间和启发式百分比。只有配置 `CODEX_TIBO_FEED_URL` 才发起请求；默认关闭，支持 BetterOPC 兼容公开源，缓存约 60 秒，请求超时约 5 秒。失败时保留旧数据并标记过期状态。

百分比依据公开事件状态、目标时间和时效，或近期重置相关发帖频率与提示计算。它用于观察公开信号，未经统计校准，不代表 OpenAI 承诺或当前账号已经重置；0% 和 100% 也不构成保证。界面分别显示当前账号实际额度、正常重置时间和公共动态，避免把三种信息混在一起。

## 全局与项目默认 Skills

默认 Skills 新增“添加/删除”管理，并提供全局与项目两种作用域。全局默认影响全部会话，项目默认只影响该项目，统一保存到 `$CODEX_HOME/skill-defaults.json`；摘要和独立笔记不保存默认项。

新安装默认项为空。用户启用并信任摘要 hooks 后，下一条消息才提醒助手读取适用的 Skill。选择、保存或收到提醒都不等于已经加载或执行，移除默认项也不会卸载 Skill。

## 可选原文冷存档

新增稳定任务原文的复制存档与 Python 关键词索引。可以手动保存，或明确启用自动模式；自动模式默认关闭，只处理启用后有新活动、已结束且原文稳定的主任务。

冷档保存在 `$CODEX_HOME/cold-history`，索引需要 Python。存档保留完整原文，活跃历史不会被删除或改写。

## 启动器与安装包

Windows 启动器支持动态调试端口、窗口最大化及可选启动动画。包内附带启动演示视频，也支持随机、指定或用户自己的本地视频；遮罩按首页可见元素与布局稳定状态释放，并保留超时兜底。播放需要 `ffplay.exe`，缺播放器不阻塞 Codex。

提供两个 ZIP，均包含相同运行核心与本地资产后端。

- `codex-sidebar-enhancer-windows.zip` 用于常规 Windows 安装。
- `codex-workspace-enhancer-skill.zip` 附带自包含的安装、诊断、配置和验收说明；inspect/verify 支持自定义检查路径，安装使用 LOCALAPPDATA 下的专属目录。

需要 Windows、Node.js >=22.13.0 和 Codex Desktop。正常退出 Codex 后，通过增强器快捷方式启用调试入口；安装不强制关闭应用。程序与用户状态分离，升级保留配置和资产，旧独立资产服务不会自动迁移。端口冲突会报告，不终止其他服务。

## 保留能力与使用边界

任务卡片与列表、置顶/项目/最近导航、独立摘要与笔记、Skill 分类/收藏及原生附件、本地项目资产、多类型预览、来源引用、MJ 分组与复制 `--p` 继续保留并整合。

MOKE、CortexDB、Tibo 公共源、冷存档和会话整理均需各自配置或启用。内嵌浏览器受站点与宿主策略限制，保存页签不等于保存网页进程或任意网站登录状态。保留的 macOS 入口没有本版真机验证。公开包不携带账号、个人会话、项目素材或私有 Skill。
